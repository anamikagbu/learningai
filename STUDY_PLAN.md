# 12-Month AI and Data Science Study Plan

**Learner:** Anamika Pradhan  
**Program:** B.Tech Data Science, Gautam Buddha University  
**Target outcome:** become internship-ready with a credible public portfolio by the end of 12 months.

## Outcome goals

1. Complete six end-to-end projects with polished documentation.
2. Build two deployed applications: one analytics dashboard and one ML API or app.
3. Solve at least 150 SQL/Python problems and 100 practical ML exercises.
4. Publish one technical write-up or project update each month.
5. Apply to internships, research roles, and open-source opportunities from Month 9.

## Weekly routine

- **5 days:** 60-90 minutes of focused study or coding
- **1 day:** 2-3 hours for the weekly project
- **1 day:** review, documentation, and rest
- Every week: commit useful work, write what was learned, and record one blocker

## Monthly milestones

| Month | Focus | Deliverable |
|---|---|---|
| 1 | Python, Git, Linux, problem solving | Python fundamentals repo + 25 problems |
| 2 | SQL and databases | SQL case study with 30 queries |
| 3 | Statistics and EDA | EDA project with a clear data story |
| 4 | Supervised ML | Regression/classification comparison |
| 5 | Feature engineering and unsupervised ML | Clustering or recommendation project |
| 6 | Model evaluation and explainability | Reproducible ML pipeline |
| 7 | Deep learning with PyTorch/TensorFlow | Image or tabular neural-network project |
| 8 | NLP and modern AI concepts | Text classification or semantic search project |
| 9 | APIs, Streamlit, Docker | Deploy one model-backed application |
| 10 | Cloud/MLOps basics | CI checks, experiment tracking, deployment notes |
| 11 | Capstone project | Real-world problem, dataset, model, demo |
| 12 | Portfolio and applications | Six polished projects + applications |

## Portfolio project ladder

1. **Data analysis:** public Indian education, climate, or transport dataset.
2. **Predictive ML:** explainable model with a meaningful baseline.
3. **Recommendation or clustering:** user-focused insights and evaluation.
4. **Deep learning:** image, time-series, or tabular problem.
5. **NLP:** classification, search, or retrieval with error analysis.
6. **Capstone:** a useful AI product connected to a real social or campus problem.

## Definition of done for every project

- Problem and user clearly stated
- Data source and license recorded
- Baseline established before tuning
- Metrics selected and interpreted
- Limitations and ethical risks documented
- Reproducible setup instructions included
- Demo, screenshots, or sample output provided
