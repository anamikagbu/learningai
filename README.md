# Learning AI

A structured portfolio for my journey as a B.Tech Data Science student at Gautam Buddha University.

## Purpose

This repository tracks hands-on learning in Python, SQL, statistics, machine learning, deep learning, NLP, and deployment. Each project should include a clear problem statement, reproducible setup, results, and lessons learned.

## Roadmap

See [STUDY_PLAN.md](STUDY_PLAN.md) for the 12-month plan, weekly routine, milestones, and portfolio targets.

## Project standards

- Use a separate folder for each project.
- Include a README with problem, data source, approach, metrics, and limitations.
- Keep notebooks readable and move reusable code into modules.
- Track experiments and explain model decisions.
- Never commit secrets, credentials, or private data.

## Suggested structure

```text
learningai/
├── projects/
├── notebooks/
├── src/
├── data/             # small samples or download instructions only
├── requirements.txt
├── STUDY_PLAN.md
└── README.md
```
